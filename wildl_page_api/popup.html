Настройки загрузки⌄

По умолчанию: отдельные MP4 и максимальное качество каждой серии. Поддерживаемый HLS перепаковывается в MP4 без потери качества. ZIP ограничен 4 ГБ.

JPG по умолчанию: готовые JPEG сохраняются как есть, остальные страницы преобразуются с качеством 95%. PNG — без дополнительных потерь, обычно больше. Формат меняется после скачивания и не уменьшает трафик; прозрачность JPG заменяется белым фоном.

Больше потоков может ускорить загрузку, но повышает риск лимита. Интервал — пауза каждого потока между главами. Время ожидания сервера имеет приоритет.

Базовую папку загрузок можно изменить в настройках браузера.

Для ZIP нужны сохранённые серии, временный архив и итоговый файл. Если места мало, выберите «По одному файлу» или другой диск для загрузок.
