# WildLib

**WildLib 2.3**. Расширение для Chromium и Firefox. Загружает любимые произведения: новеллы, манги и аниме с сайтов группы Lib.

Поддерживаемые адреса и обновление зеркал через публичные каналы Telegram находятся в **Настройки загрузки → Сайты и зеркала**. [Список зеркал и источники](docs/MIRRORS.md).

Для ZIP используются ссылки на уже сохранённые серии: расширение не создаёт отдельную полную временную копию архива. Для видео размером около 3,5 ГБ сохранённые серии и итоговый ZIP вместе занимают около 7 ГБ, плюс служебные данные и запас браузера. После ошибки можно нажать **Сохранить серии по одному файлу** без повторного скачивания. Изменение папки загрузок не переносит внутреннее хранилище профиля браузера. Серии удаляются из него только после подтверждения успешной записи.

[Скачать расширение](https://github.com/WildLIK/WildLib/releases/latest) · [Изменения версии 2.3](docs/RELEASE-2.3.md)

## Дисклеймер

Проект не связан с администрацией AnimeLib, MangaLib и RanobeLib. Все права на контент принадлежат правообладателям. Расширение предназначено только для личного офлайн-доступа. Пользователь самостоятельно несёт ответственность за соблюдение авторских прав и правил площадок.

## Возможности

| Сайты | Содержимое | Форматы |
| --- | --- | --- |
| RanobeLib | Новеллы | EPUB, TXT, FB2, PDF, DOCX, MOBI |
| MangaLib, HentaiLib, SlashLib | Манга | CBZ, ZIP, CBR |
| AnimeLib | Аниме через AnimeLib и Kodik | Отдельные MP4, ZIP; исходный MP4/TS по выбору |

- Выбор переводчика, озвучки или субтитров и диапазона глав/серий.
- Раздельные группы озвучки и субтитров, с номерами доступных серий.
- Проверка разрешений выбранной озвучки, включая 4K и список серий, где оно доступно.
- Сканирование только нужного диапазона: например, 1180–1182, без проверки тысячи предыдущих серий.
- Пауза, остановка, продолжение прерванной загрузки и сохранение скачанной части.
- Контрольные точки в IndexedDB: готовые главы/серии сохраняются между перезапусками расширения.
- При сохранении архива контрольные точки удаляются только после подтверждения успешной записи браузером. Если запись прервана, скачанную часть можно сохранить повторно; журнал показывает код ошибки браузера.
- Видео сохраняется порциями в файловом хранилище профиля браузера (OPFS); IndexedDB хранит только небольшие ссылки на файлы. ZIP собирается из ссылок на неизменяемые файлы серий и служебных блоков, без полной промежуточной копии. Контрольные суммы рассчитываются порциями по 4 МиБ. Недоступные сохранённые серии исключаются из готовой части и восстанавливаются при продолжении.
- По умолчанию поддерживаемый TS (H.264/AAC) перепаковывается в MP4 без перекодирования. Дорожки проверяются, длительность MP4 заполняется; неподдерживаемые дорожки не удаляются молча — показана ошибка с предложением исходного контейнера. Прямой MP4 сохраняется как есть.
- По умолчанию видео сохраняется отдельными файлами в `Загрузки/WildLib/Название сериала/`, без ZIP. Имя: «Название сериала. Номер серии.mp4» или `.ts`; при повторении номеров добавляется сезон. ZIP остаётся доступен, видео в нём лежит без папок для каждой серии.
- Максимальное доступное качество выбирается отдельно для каждой серии по умолчанию; фиксированное качество можно выбрать вручную.
- До четырёх параллельных HLS-фрагментов или MP4-диапазонов; при 429/503 общий перерыв и снижение числа потоков. Готовые фрагменты сохраняются в файловом хранилище браузера и используются при продолжении.
- MP4-диапазоны включаются только при подтверждённых `206`, размере и валидаторе версии; неподдерживаемый Range переключается на обычную загрузку.
- Кнопка «Рекомендуемые настройки» возвращает исходные параметры; ручные настройки запоминаются отдельно для книг, манги и аниме.
- Примерное время текущей серии рядом со статусом: по объёму MP4 или ходу HLS, с исключением пауз, перерывов и сохранённых частей. Неизвестный размер и начальный этап показываются как «Оцениваю время…».
- Журнал до 300 событий с временем: плеер, качество, сервер без подписанных URL, режим, восстановленные части, повторы, размер, время, средняя скорость и результат сохранения.
- Компактный интерфейс с подсветкой, индикаторами поиска/загрузки и анимированным логотипом при скачивании/сохранении. На паузе и после окончания логотип статичен. Вокруг процентов движется световая волна; прогресс закреплён рядом с кнопками.
- Общий прогресс аниме учитывает скачиваемую часть текущей серии: MP4 — по байтам, HLS — по фрагментам. Во время загрузки показаны скорость и размер видео, если сервер сообщает его.
- Общий лимит запросов API для поиска и загрузки; ожидание при 429 распространяется на все потоки задания.
- ComicInfo.xml в архивах манги: название, источник, фактическое число страниц и список сохранённых глав; авторы, художники, описание и жанры — если сайт вернул их.
- Параллельные страницы манги и единый JPG по умолчанию: исходный JPEG копируется без изменений, остальные форматы преобразуются с качеством 95%, без изменения размеров. Прозрачность заменяется белым фоном. В настройках доступны PNG, WebP и исходные форматы; конверсия в статичный формат сохраняет первый кадр анимированных изображений.
- Сжатие текстовых частей EPUB и DOCX без потери текста.
- История последних 100 сохранений: результат, формат, диапазон, перевод, размер и путь к файлу.
- Сохранение в подпапку WildLib внутри загрузок браузера без диалога, с настройкой подпапки и включением диалога при необходимости.

## Установка

### Firefox

Для обычной постоянной установки нужен **XPI, подписанный Mozilla**: откройте `about:addons` → шестерёнка → **Установить дополнение из файла…** → выберите подписанный XPI → **Добавить**. После перезапуска Firefox расширение останется установленным. Версия отправлена на проверку Mozilla; подписанного XPI пока нет. Ниже приведён способ временной установки текущей сборки. [Подготовка подписи и простая установка](docs/FIREFOX.md).

Скачайте **WildL-Downloader-2.3-Firefox.zip** из [GitHub Releases](https://github.com/WildLIK/WildLib/releases/latest) и распакуйте его. Откройте `about:debugging` → **Этот Firefox** → **Загрузить временное дополнение** и выберите `manifest.json` в распакованной папке. Нужен Firefox 128 или новее. Временное дополнение действует до закрытия Firefox. Для обычной постоянной установки нужен подписанный Mozilla XPI; ZIP не подписан. [Инструкция Mozilla](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

### Chromium

Скачайте **WildL-Downloader-2.3.zip** из [GitHub Releases](https://github.com/WildLIK/WildLib/releases/latest) и распакуйте папку расширения. Можно также установить исходники из репозитория:

1. Скачайте этот репозиторий через **Code → Download ZIP** и распакуйте его, либо клонируйте:

   ```sh
   git clone https://github.com/WildLIK/WildLib.git
   ```

2. Откройте `chrome://extensions` в Chrome или `browser://extensions` в Яндекс Браузере.
3. Включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
4. Выберите папку **WildL-Downloader-2.3** из архива выпуска или **wildl_page_api** из репозитория, содержащую `manifest.json`.
5. Перезагрузите уже открытые вкладки Lib и откройте расширение по его значку.

Сборка и установка npm-зависимостей для использования расширения не нужны. В репозитории находятся готовые файлы расширения; CRX можно собрать средствами браузера.

Chrome на Windows и macOS может блокировать CRX, установленный вне Chrome Web Store. Для локального использования устанавливайте распакованную папку указанным выше способом. [Пояснение Chrome](https://support.google.com/chrome_webstore/answer/2811969?hl=ru).

При обновлении файлов нажмите кнопку обновления расширения на странице управления расширениями, затем перезагрузите вкладку Lib. Одновременно используйте одну установленную копию.

## Уведомления об обновлениях

Каждая новая версия публикуется в [GitHub Releases](https://github.com/WildLIK/WildLib/releases). Чтобы получать уведомления на GitHub или по почте согласно настройкам аккаунта, включите **Watch → Custom → Releases** на странице репозитория.

## Использование

### Новеллы и манга

Откройте тайтл на поддерживаемом сайте. Выберите переводчика, диапазон, формат и нажмите **Скачать**. Главы без выбранного перевода пропускаются с записью в журнале и отчёте архива.

### Аниме

1. Откройте фильм или сериал на AnimeLib.
2. Укажите номера в полях **С серии** и **По серию**.
3. Нажмите **Сканировать диапазон** и выберите озвучку или субтитры.
4. Дождитесь проверки качества. Подсказка покажет доступные разрешения и конкретные серии с 4K. Кнопка **Проверить качество** повторяет проверку.
5. Выберите качество и нажмите **Скачать серии**.

Для тайтлов до 100 серий озвучки проверяются автоматически. Для более длинных сначала загружается общий список, а проверка нужных серий запускается вручную. **Все серии** запускает полное сканирование. Во время долгого поиска или ожидания лимита можно задать меньший диапазон и начать его сканирование.

Качество проверяется у выбранного перевода и плеера. Если проверка не удалась, оно отображается как неизвестное. Значок 4K у другой озвучки не гарантирует 4K у выбранной. При отсутствии выбранного плеера используется Kodik только с той же командой и типом перевода.

### Продолжение

Если исходная страница перезагружена, закрыта или выгружена браузером, откройте исходный тайтл и нажмите **Продолжить загрузку**. Уже полностью сохранённые главы/серии повторно не скачиваются. Сохранённые фрагменты HLS и MP4-диапазоны используются при продолжении; обычный MP4 без Range загружается заново, если серия не была завершена.

- **Пауза** приостанавливает текущее задание.
- **Стоп** прерывает загрузку, сохраняя готовую часть для продолжения.
- **Сохранить скачанное** собирает архив из готовой части.
- **Обновить** перезапускает расширение; окно закроется, после чего откройте его снова по значку.
- **Начать другую загрузку** очищает прежнее задание и определяет текущий тайтл.

## Настройки

| Настройка | Что меняет |
| --- | --- |
| Глав одновременно | 1–6 потоков для книг и манги. Больше потоков может ускорить загрузку, но увеличивает вероятность лимита сервера. |
| Интервал | Пауза каждого потока между главами. Для аниме — пауза между сериями; видео скачивается последовательно. Поиск озвучек и проверку качества этот параметр не замедляет. |
| Запросов API в минуту | Общий темп запросов к API Lib для списка глав/серий, проверки озвучек и получения глав. По умолчанию 60; 1–120. Меньше — медленнее поиск и ниже нагрузка. Не ограничивает отдельные изображения, видео и запросы к Kodik для проверки качества. |
| Страниц одновременно | 1–6 страниц одной главы, по умолчанию 3. На всё задание одновременно выполняется не больше 6 загрузок страниц. Работает только для манги. |
| Размер страниц | «Исходные» запрашивает исходный сервер. «Сжатые с сайта» запрашивает сжатый вариант площадки и может уменьшить трафик. Итоговый формат выбирается отдельно. |
| Формат всех страниц | JPG по умолчанию (95% для конверсии; готовый JPEG без перекодирования), PNG без дополнительных потерь, WebP 90% или исходные форматы. Единый формат не заменяется исходным даже при увеличении размера; при невозможности конверсии показана ошибка, неверное расширение не присваивается. |
| Фрагментов видео одновременно | По умолчанию 4, диапазон 1–6. Применяется к HLS и проверенным диапазонам MP4; серии идут по очереди. После 429/503 число потоков уменьшается до конца задания. |
| Скачивать MP4 по частям | По умолчанию включено. Проверяется Range; части по 8 МиБ, `Content-Range`, `If-Range` и версия файла. Без подходящего ответа или валидатора используется обычный запрос. |
| Контейнер видео | MP4 по умолчанию. Поддерживаемый MPEG-TS перепаковывается в фоновом worker без перекодирования; прямой MP4 не меняется. «Исходный MP4 / TS» сохраняет исходный контейнер. |
| Качество видео | «Максимальное» по умолчанию — лучшее качество каждой серии; 4K не заменяется выбранной другой озвучкой. Ручной выбор качества сохраняется. |
| Ожидание при лимите API | Время до повторного запроса, если сервер не сообщил свой срок ожидания. Указания сервера имеют приоритет. |
| Подпапка в Загрузках | Например WildLib или WildLib/Anime. Пустое поле сохраняет в корень загрузок. Абсолютный путь не поддерживается; базовую папку меняйте в настройках браузера. |
| Спрашивать место сохранения | По умолчанию выключено. Если включить — появляется диалог сохранения. Совпадающие имена получают новый номер вместо перезаписи файла. |

Параметры применяются при запуске задания. Они регулируют нагрузку и ожидание, но не меняют наличие переводов, разрешений или доступ к содержимому.

Настройка папки применяется при сохранении файла. **История загрузок** находится внутри **Настроек загрузки**, хранится только в этом профиле браузера и заполняется при передаче файла на сохранение. «Очистить» удаляет записи истории, не файлы на диске. После завершения доступна кнопка «Показать файл», пока запись существует в менеджере загрузок браузера.

## Ограничения

- Получается только содержимое, доступное текущему сеансу пользователя на сайте.
- Ограничения серверов соблюдаются; при лимите загрузчик ждёт.
- Зашифрованные HLS-потоки, прямые трансляции и HLS с отдельной аудиодорожкой не поддерживаются.
- ZIP ограничен примерно 4 ГБ. Для отдельных файлов, собираемых из HLS-фрагментов или проверенных MP4-диапазонов, лимит ZIP не применяется. Обычный MP4 без поддержки диапазонов ограничен примерно 4 ГБ и требует больше памяти. Для обычного MP4 без Range целиком загружается незавершённая серия; уже готовые серии сохраняются.
- Фрагменты занимают хранилище браузера. При нехватке места показана ошибка, сохранённые части остаются для продолжения. При изменении URL/плейлиста или версии файла несовместимые части удаляются, чтобы не смешать разные видео.
- Раздельные дорожки HLS/DASH, DRM и перекодирование не добавлены; скачивается исходное поддерживаемое видео. Для использования расширения отдельные программы не нужны. Перепаковка TS → MP4 поддерживает H.264/AAC; HEVC и другие неподдерживаемые дорожки TS требуют выбора исходного контейнера. Прямые MP4 с другими кодеками сохраняются как есть.
- Изменения API сайтов или плееров могут потребовать обновления расширения. Состояние загрузки и причины отказа показаны в журнале.

## Разработка и проверки

Нужен Node.js 20 или новее. Зависимости используются только для тестов:

```sh
npm ci
npm test
```

Основные проверки не требуют браузера: жизненный цикл моста страницы, работа после перезапуска, проверка качеств Kodik, выбор MP4/HLS и ожидание лимита.

Проверки интерфейса и настоящего MV3-расширения с синтетическими API и видео:

```sh
npx playwright install chromium
npm run test:ui
```

## Структура

- `wildl_page_api/` — файлы устанавливаемого расширения.
- `tests/` — самостоятельные проверки на синтетических данных.
- `scripts/test.cjs` — запуск проверок.
- `scripts/build-test.cjs` — подготовка папки Chromium или Firefox (`--firefox`); для выпуска добавьте `--release`, для неподписанного пакета Mozilla — `--firefox --release --xpi`.
- `wildl_page_api/vendor/` — локальные зависимости PDF и уведомления об их лицензиях.

В проект включены pdf-lib и fontkit под MIT, а также Noto Serif под SIL OFL 1.1. Их лицензии сохранены рядом с файлами в `vendor/`.

Встроенная библиотека перепаковки: [mux.js 6.3.0](https://github.com/videojs/mux.js/tree/v6.3.0), Apache-2.0. Код и лицензия поставляются локально; загрузки скриптов с CDN во время работы нет.
