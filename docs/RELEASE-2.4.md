# WildLib 2.4

- Исправлены ошибки сохранения больших видео и ZIP в Chrome и Яндекс Браузере. При ошибке скачанные серии остаются для продолжения или сохранения отдельно.
- Уменьшен расход временного места при сборке ZIP. Успешное завершение показывается после записи файла на диск.
- Добавлены зеркала RanobeLib, AnimeLib и SlashLib, ручное подключение адресов и необязательная ежедневная проверка публичных каналов Telegram.
- В настройках появились переход к выбору папки загрузок браузера и переключатель автосохранения без запросов. В Firefox доступна инструкция.
- Уточнены названия форматов: «Одним архивом» и «По одному файлу». Закреплённый блок прогресса и кнопок получил аккуратную рамку.
- Название проекта и расширения — WildLib. История и данные для продолжения сохранены.

## Установка

**WildLib-2.4.zip** — Chrome, Яндекс и другие совместимые Chromium-браузеры. Распакуйте и загрузите папку через режим разработчика. При обновлении замените файлы в текущей папке расширения и перезагрузите его и вкладки Lib.

**WildLib-2.4-Firefox.zip** — Firefox 128+: временная установка через `about:debugging`. Для постоянной установки требуется подписанный Mozilla XPI; этот ZIP не подписан.

Для сохранения на другой диск один раз выберите папку в настройках браузера и отключите постоянный запрос места сохранения. Прямой выбор произвольной папки из расширения в этой версии не добавлен.

ZIP — до 4 ГБ. DRM и зашифрованный HLS не поддерживаются.
