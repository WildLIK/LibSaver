# Сравнение загрузчиков Lib

Проверено по исходному коду 11 октября 2026 года и дополнено замерами 12 октября. Ссылки закреплены на проверенных коммитах. Ядра чужих загрузчиков запущены на одинаковом локальном наборе; сделаны и попытки на живом сайте. Их собственные наборы тестов не выполнялись. [Результаты и ограничения замеров](BENCHMARK.md).

## DownloadLib — ivanvit100

[Репозиторий](https://github.com/ivanvit100/DownloadLib/tree/61c9edf2154fcd977b6180ccbc7d8c628dc1b2fc).

Сильные стороны:

- Отдельные сборки для Chromium и Firefox; Firefox для Android заявлен как бета.
- FB2, EPUB, MOBI, PDF, TXT и ZIP с изображениями. Есть плагины, включая CBZ.
- Разбиение загрузки на части по размеру, обработка длинных страниц и подгонка изображений для FB2 — полезно для электронных читалок.
- Общая очередь запросов, лимит в минуту и общий срок ожидания после ограничения сервера.
- История успешных загрузок, адаптеры сайтов, экспортёры и многочисленные тесты.

Ограничения:

- В проверенной версии не найден адаптер AnimeLib.
- [Chrome-манифест](https://github.com/ivanvit100/DownloadLib/blob/61c9edf2154fcd977b6180ccbc7d8c628dc1b2fc/manifest.chrome.json) запрашивает доступ ко всем HTTPS-сайтам. Это шире доступа LibSaver к определённым доменам.
- [DownloadManager](https://github.com/ivanvit100/DownloadLib/blob/61c9edf2154fcd977b6180ccbc7d8c628dc1b2fc/core/DownloadManager.js) держит активные задания в памяти; в просмотренном коде не обнаружены контрольные точки содержимого в IndexedDB, аналогичные LibSaver. Пауза и история успешных загрузок не равнозначны восстановлению после закрытия браузера.
- Плагины и несколько браузерных сборок усложняют сопровождение. Это оценка архитектуры, а не измерение количества ошибок.
- Рекомендация скачать CRX сама по себе не решает ограничения Chrome на установку вне магазина.

В пакете и заголовках исходников указана лицензия MIT. Полезные идеи для LibSaver: [общий ограничитель запросов](https://github.com/ivanvit100/DownloadLib/blob/61c9edf2154fcd977b6180ccbc7d8c628dc1b2fc/core/RateLimiter.js), разделение больших архивов, экспорт для читалок.

## Lib-downloader — Feqwy

[Репозиторий](https://github.com/Feqwy/Lib-downloader/tree/2058c06aa705652f04836f95f6c0d0b556ed1efd).

Сильные стороны:

- Асинхронный Python-загрузчик с отдельными ограничениями числа глав и изображений.
- Работа с папками на диске: поиск недостающих глав и пакетное пополнение из CSV.
- ComicInfo.xml, series.json и обложки для каталогизации манги; [генератор метаданных](https://github.com/Feqwy/Lib-downloader/blob/2058c06aa705652f04836f95f6c0d0b556ed1efd/metadata.py).
- Сборка CBZ и структура библиотеки по томам/главам.
- Поддерживаются MangaLib, SlashLib, HentaiLib и RanobeLib.

Ограничения:

- Требуются Python, зависимости и отдельный сервер; расширение служит интерфейсом к нему и передаёт ему авторизацию сайта. Установка сложнее загрузки одной папки расширения.
- Адаптер AnimeLib в проверенной версии отсутствует.
- Для ранобэ код сохраняет HTML/TXT глав; экспортёры EPUB/FB2/PDF/DOCX не найдены.
- В проверенном дереве не найдены автоматические тесты и файл лицензии. Перед переносом исходников нужно уточнять разрешение автора.
- Проверка «обновлений» в README относится прежде всего к новым главам локальной библиотеки; это не подтверждение автоматического обновления программы.

Полезные идеи для LibSaver: ComicInfo, история тайтлов с догрузкой новых глав и работа с большой библиотекой на диске.

## LibSaver 2.3

Сохранены аниме через AnimeLib/Kodik, проверка диапазона озвучек и качества, DOCX, загрузка без Python и контрольные точки готовых глав/серий. Добавлены четыре параллельных видеофрагмента, сохранение частичного HLS/MP4, отдельные видеофайлы без ZIP, максимальное качество по умолчанию, отдельная сборка Firefox, MOBI 6, история, сохранение в подпапку без диалога, параллельные страницы, сжатие текста EPUB/DOCX и необязательный WebP. Общая очередь API с паузой после 429 и ComicInfo в CBZ/ZIP/CBR также сохранены. Реализация написана для текущей архитектуры, без переноса исходников этих проектов.

Лимит API относится к запросам Lib текущего задания. Он не считает всю сетевую активность браузера, изображения и сегменты видео; уже отправленные запросы нельзя отменить ответом 429 на другой запрос. Ограничения сайта остаются возможны.

Остаются преимущества других проектов, которых пока нет в LibSaver: автоматическое разбиение большого архива и синхронизация с существующей библиотекой на диске. История LibSaver показывает сохранённые файлы и открывает тайтлы, но не является очередью нескольких тайтлов или автоматической догрузкой новых глав. Архив ограничен 4 ГБ; для больших загрузок нужно выбирать меньший диапазон.

Проверки новых функций используют синтетические главы и видео: равномерность параллельных API-запросов, общий Retry-After, пауза/продолжение, отмена очереди, реальные CBZ/ZIP/CBR и ComicInfo при восстановлении частичной загрузки из IndexedDB. Совместимость метаданных со всеми сторонними читалками отдельно не проверялась.
