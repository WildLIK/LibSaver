# Зеркала сайтов Lib

Проверено 13 октября 2026 года. Доступность адреса зависит от сети и состояния самого сайта; поддержка адреса расширением не гарантирует, что он откроется у каждого пользователя.

| Сайт | Домены, которые распознаёт WildLib |
| --- | --- |
| MangaLib | mangalib.me, mangalib.org |
| RanobeLib | ranobelib.me, ranobelib.org, novelslib.me |
| AnimeLib | animelib.org, animelib.me, anilib.me |
| HentaiLib | hentailib.me, hentailib.org |
| SlashLib | slashlib.me, slashlib.org, shlib.life, yaoilib.net |

Для встроенных доменов поддерживаются поддомены, в том числе `v1`, `v2`, `v3`, `v5` и следующие номера. Дополнительный список номеров не нужен.

Подтверждения: [MangaLib о зеркалах AnimeLib и RanobeLib](https://t.me/s/mangalib_social?before=311), [SlashLib о v1.yaoilib.net](https://t.me/s/slashlibme?before=17), [AnimeLib на anilib.me](https://anilib.me/). Адрес v1.yaoilib.net при проверке перенаправлял на v2.shlib.life. Новых независимых доменов HentaiLib из подтверждённого канала при этой проверке не найдено.

Откройте **Настройки загрузки → Сайты и зеркала**. Здесь можно открыть известный адрес, добавить HTTPS-зеркало вручную или проверить публичные каналы `@mangalib_social` и `@slashlibme`. Расширение читает только публичные веб-ленты этих каналов, без авторизации, бота и передачи информации о скачиваемых произведениях.

Ежедневную проверку можно включить флажком. По умолчанию она выключена. Ручные запросы ограничены одним в минуту. При недоступности Telegram сохранённые адреса остаются, скачивание не блокируется. Проверяется доступная публичная лента, а не вся история канала. Приватные каналы и сообщения, скрытые веб-просмотром Telegram, этим способом прочитать нельзя.

Адреса из сообщений появляются как предложения со ссылкой на источник. Новый домен не активируется автоматически: выберите сайт и нажмите **Подключить**. Браузер запрашивает доступ только к выбранному HTTPS-адресу. При ручном подключении разрешение действует на точный хост, а не на все его поддомены. Публикации каналов не исполняются как код. Подключение зеркала означает выбор адреса пользователем, а не автоматическую проверку его принадлежности площадке.

Чтобы отключить вручную добавленный адрес, нажмите **Отключить**. Чтобы прекратить проверки Telegram, снимите флажок. Выданные разрешения браузера можно отдельно отозвать в настройках расширения.
