# Установка в Firefox

## Обычная установка

Для постоянной установки нужен файл `.xpi`, подписанный Mozilla. Версия отправлена на проверку Mozilla. Текущий ZIP предназначен для временной установки, подписанный файл пока не получен.

Когда подписанный XPI будет добавлен к выпуску на GitHub:

1. Скачайте файл XPI.
2. В Firefox откройте `about:addons`, нажмите шестерёнку и **Установить дополнение из файла…**.
3. Выберите XPI и подтвердите **Добавить**.

Расширение останется установленным после закрытия браузера. Дополнительные программы и режим разработчика не нужны. [Инструкция Mozilla](https://support.mozilla.org/en-US/kb/find-and-install-add-ons-add-features-to-firefox).

Альтернатива — публикация в каталоге Firefox Add-ons: пользователи смогут нажать **Добавить в Firefox**, а обновления будет устанавливать браузер. Для распространения через GitHub достаточно подписи без публичной страницы в каталоге. [Варианты распространения](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/).

## Получение подписи — один раз для автора каждой версии

1. Войдите под своим аккаунтом Mozilla в [кабинет разработчика](https://addons.mozilla.org/developers/addon/submit/distribution).
2. Для распространения через GitHub выберите **On your own** — самостоятельное распространение.
3. Загрузите подготовленный архив Firefox с `manifest.json` в корне. Архив для подписи называется `WildL-Downloader-2.3-Firefox-unsigned.xpi`; он ещё не подходит для обычной установки.
4. Завершите проверку Mozilla. Если сервис запросит исходники или исправления, выполните его требования. Для сторонних библиотек сведения о версиях, источниках и лицензиях находятся в `vendor/`.
5. Скачайте **подписанный** XPI из страницы версии в кабинете разработчика. Именно его можно разместить на GitHub как `WildL-Downloader-2.3-Firefox.xpi`.

Загрузку следует выполнять под аккаунтом автора проекта. Подпись выдаёт Mozilla после проверки; расширение не может подписать себя. После получения подписи содержимое XPI нельзя изменять — правка требует новой подписи. [Порядок подачи](https://extensionworkshop.com/documentation/publish/submitting-an-add-on/).

Создать пакет из исходников: `node scripts/build-test.cjs --firefox --release --xpi`. В пакете `manifest.json` лежит в корне; исходники приложения не минифицируются дополнительно, локальные сторонние библиотеки и их лицензии сохранены.

## Установить текущую сборку временно

Распакуйте Firefox ZIP. Откройте `about:debugging` → **Этот Firefox** → **Загрузить временное дополнение** и выберите `manifest.json`. Такая установка действует до закрытия Firefox. Для постоянной установки используйте подписанный XPI указанным выше способом.
