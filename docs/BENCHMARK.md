# Скорость и размер: 2.3

Замеры выполнены 11–12 октября 2026 года на этом компьютере во время разработки 2.3.

## Одинаковый контролируемый тест манги

Три главы по 24 страницы, всего 72 JPEG размером 146 725 байт каждый. Изображения синтетические, 320×450; задержка локального сервера — 80 мс для API и 120 мс для страницы. Каждый режим запущен три раза, таблица показывает медиану. Все архивы проверены на наличие всех 72 страниц.

Запускались исходные DownloadManager, сервис MangaLib, RateLimiter и SimpleExporter проекта [DownloadLib](https://github.com/ivanvit100/DownloadLib/tree/61c9edf2154fcd977b6180ccbc7d8c628dc1b2fc), полный ChapterDownloader проекта [Lib-downloader](https://github.com/Feqwy/Lib-downloader/tree/2058c06aa705652f04836f95f6c0d0b556ed1efd) и загрузчик/IndexedDB/экспорт WildLib. Исходники чужих проектов не менялись. В браузерном контролируемом тесте мост расширения к вкладке заменён адаптером к локальному серверу; это измерение ядра загрузки, не полного интерфейса или реального CDN. Запуск браузера и импорт модулей исключены из времени.

| Режим | Время | Архив, МБ (1 МБ = 1 000 000 байт) |
| --- | ---: | ---: |
| DownloadLib, исходные настройки JPEG | 2,71 с | 8,20 |
| Lib-downloader, 1 глава / 5 изображений, задержка 0,5 с | 12,82 с | 10,54 |
| WildLib, страницы последовательно | 9,21 с | 10,58 |
| WildLib, 3 страницы одновременно | 6,17 с | 10,58 |
| WildLib, 3 страницы + WebP | 6,38 с | 6,24 |

DownloadLib допускает короткий залп в рамках лимита 85 запросов/минуту и перекодирует JPEG с качеством 0,92. WildLib здесь использует равномерные 60 API-запросов/минуту и две главы одновременно; CDN-запросы регулируются отдельным числом страниц. Lib-downloader использует параметры, предложенные его интерфейсом: одна глава, пять страниц и пауза 0,5 с. Различия настроек являются частью результата, поэтому таблица не доказывает, что один проект всегда быстрее другого. Размеры также не сравнивают одинаковое качество: JPEG DownloadLib и WebP WildLib — перекодирование с потерями, остальные режимы сохраняют исходные JPEG.

Параллельность уменьшила время WildLib на 33% (примерно в 1,49 раза быстрее). WebP уменьшил архив на 41%, но не сетевой трафик. Отдельный замер CRC32 на 10 МиБ: старая побитовая функция — 71,24 мс, новая таблица — 16,50 мс, примерно в 4,3 раза быстрее; контрольные суммы совпали. Это ускорение проверки/упаковки, не всей загрузки.

## Попытка измерить живой RanobeLib

Проверка без авторизации в отдельном браузерном профиле получила HTTP 200: список 3621 главы «Теневого раба» — 4,17 МБ JSON за 4,761 с; первая глава — 59 349 байт JSON за 0,458 с. Эти числа относятся к двум запросам, а не полной загрузке произведения.

Полный DownloadLib был отдельно загружен как настоящее MV3-расширение в Chromium. На запросе списка глав он остановился с `Failed to fetch chapters: 0`. Следующий запрос списка из браузера тоже завершился сетевой ошибкой; Python-клиент Lib-downloader получил HTTP 500. Сопоставимый успешный замер всех трёх на живом сайте поэтому не получен. Это результат конкретных попыток в чистых профилях, не доказательство общей неработоспособности проектов. Нельзя переносить времена локального теста на Интернет.

## Что изменено

- 1–6 страниц манги одновременно; по умолчанию 3, общий максимум 6 активных страниц на задание. Порядок файлов сохраняется, неполная глава не попадает в контрольные точки.
- Табличный CRC32 вместо восьми побитовых операций на байт.
- DEFLATE для текстовых частей EPUB/DOCX; обязательный `mimetype` EPUB остаётся несжатым. Содержимое восстанавливается без потерь.
- Выбор исходных страниц, сжатого сервера сайта или WebP 0,82. Сжатый сервер запрашивается параметром `server=compress`; экономия трафика зависит от ответа площадки. WebP работает после получения оригинала и сохраняется только если оказался меньше; размеры изображения не меняются. GIF/AVIF не перекодируются.
- Классический MOBI 6 для ранобэ. Проверены записи UTF-8, кириллица/эмодзи на границах блоков и независимая распаковка KindleUnpack. Физические читалки отдельно не тестировались.
- Отдельная сборка Firefox. Проверены настоящий Firefox 156.0.1, инъекция MAIN, мост страницы, контрольная точка, сборка MOBI, сохранение без диалога и история. Это не проверка каждого сайта и плеера в Firefox.
- Сохранение в подпапку WildLib внутри загрузок браузера, настраиваемая подпапка и переключатель диалога. История последних 100 сохранений хранится локально.

Данные замеров и вспомогательные инструменты находятся в локальной `diagnostics/benchmark/` и не включаются в папки расширения. Ограничения доступа сайтов сохраняются. Один архив по-прежнему ограничен 4 ГБ; видео сохраняется без перекодирования.
