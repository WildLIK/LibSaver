# WildLib 2.3

Ранее проект назывался WildL Downloader / LibSaver. Расширение скачивает новеллы, мангу и аниме с сайтов группы Lib, без дополнительных программ.

## Основные изменения

- Видео сохраняется отдельными MP4 в папке сериала или одним ZIP. Имена файлов: «Название сериала. Номер серии.mp4».
- По умолчанию выбирается максимальное доступное качество. Ручной выбор, включая 4K, остаётся.
- До четырёх параллельных HLS-фрагментов или MP4-диапазонов. Полученные фрагменты сохраняются для продолжения; готовые отдельные серии не скачиваются повторно.
- Поддерживаемый HLS преобразуется в MP4 без перекодирования. Добавлены прогресс текущей серии, примерное время завершения и подробный журнал.
- Страницы манги — JPG по умолчанию; доступны PNG, WebP и исходные форматы. Параллельная загрузка страниц и ComicInfo.xml в CBZ/ZIP/CBR.
- Для новелл добавлен MOBI к EPUB, TXT, FB2, PDF и DOCX.
- Анимированный логотип, история последних 100 сохранений, рекомендуемые настройки и сохранение без запроса папки. Добавлена сборка Firefox.

## Установка

- **WildL-Downloader-2.3.zip** — Chrome, Яндекс и другие Chromium-браузеры: распакуйте и загрузите папку через режим разработчика.
- **WildL-Downloader-2.3-Firefox.zip** — Firefox 128+: временная установка через `about:debugging`. Постоянная установка требует подписанного Mozilla XPI; опубликованный ZIP не подписан.

Имена архивов этого выпуска сохранены. После обновления перезагрузите расширение и вкладки Lib.

## Ограничения

ZIP — до 4 ГБ. DRM, зашифрованный HLS, прямые трансляции и раздельные аудиодорожки HLS не поддерживаются. Возможны ограничения API сайта; больше потоков не гарантирует ускорения.
