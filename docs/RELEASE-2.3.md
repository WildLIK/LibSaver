# WildL Downloader 2.3

Версия 2.3 добавляет отдельное сохранение видео, продолжение с готовых фрагментов, сборку MP4, единый JPG для манги и сборку Firefox. Расширение работает без установки дополнительных программ.

## Аниме и видео

- По умолчанию — отдельные файлы в одной папке сериала, без ZIP. Название файла: «Название сериала. Номер серии.mp4»; сезон добавляется при повторяющихся номерах. ZIP остаётся доступен.
- Максимальное доступное качество каждой серии по умолчанию; ручной выбор, включая 4K, сохранён.
- До четырёх параллельных HLS-фрагментов или проверенных MP4-диапазонов. Если сервер не поддерживает Range, MP4 загружается обычным запросом.
- Готовые фрагменты сохраняются в хранилище браузера и используются при продолжении. Полностью сохранённые отдельные серии повторно не скачиваются.
- Единый MP4 по умолчанию: поддерживаемый MPEG-TS с H.264/AAC перепаковывается без перекодирования. Исходный контейнер можно выбрать вручную.
- Общий прогресс учитывает текущую серию: MP4 — по байтам, HLS — по фрагментам. Добавлены примерное время завершения серии, скорость и полный размер, если сервер его сообщает.
- Журнал с временем событий, качеством, режимом загрузки, восстановленными частями, повторами, размером и результатом сохранения.

## Манга и новеллы

- Единый JPG для страниц манги по умолчанию: исходный JPEG сохраняется без изменений, другие изображения преобразуются с качеством 95% и исходными размерами. В настройках доступны PNG, WebP и исходные форматы.
- Параллельное скачивание страниц манги: три страницы одной главы по умолчанию, не больше шести на задание.
- ComicInfo.xml с метаданными и фактическим числом сохранённых страниц в CBZ/ZIP/CBR.
- Классический MOBI 6 для новелл, дополнительно к EPUB, TXT, FB2, PDF и DOCX.
- Сжатие текстовых частей EPUB и DOCX без потери текста; ускорен расчёт контрольных сумм архивов.

## Интерфейс, сохранение и совместимость

- Анимированный логотип при скачивании и сохранении, статичная иконка в ожидании и на паузе. Световая волна вокруг процентов показывает активную работу.
- Статус и таймер закреплены рядом с кнопками загрузки. На ошибке — ERROR и красная рамка.
- История последних 100 сохранений, переход к тайтлу и показ сохранённого файла.
- Сохранение в подпапку LibSaver без запроса папки по умолчанию; подпапку и диалог можно изменить в настройках.
- Рекомендуемые настройки и отдельное запоминание параметров для новелл, манги и аниме.
- Общий темп API: 60 запросов в минуту по умолчанию, настройка 1–120. При ограничении сервера — общий перерыв; для видео также уменьшается число потоков.
- Отдельная сборка Firefox, исправления моста страницы после перезапуска и восстановления загрузки.
- Обновлена документация и инструкции установки.

## Установка и ограничения

- **WildL-Downloader-2.3.zip** — Chrome, Яндекс Браузер и другие совместимые Chromium-браузеры: распакуйте и загрузите папку через режим разработчика на странице расширений.
- **WildL-Downloader-2.3-Firefox.zip** — Firefox 128+: временная установка через about:debugging. Это неподписанная сборка; для постоянной установки нужен подписанный Mozilla XPI.
- Firefox-версия отправлена на проверку Mozilla. Подписанный XPI пока отсутствует.
- После обновления файлов перезагрузите расширение и открытые вкладки Lib.
- ZIP ограничен примерно 4 ГБ. Обычный MP4 без Range скачивается одним запросом; незавершённый файл в таком режиме загружается заново.
- DRM, зашифрованный HLS, прямые трансляции и раздельные аудиодорожки HLS не поддерживаются. Для TS с неподдерживаемыми кодеками выберите исходный контейнер.
